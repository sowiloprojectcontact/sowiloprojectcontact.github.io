Suppression des données

Mise à jour : 27 octobre 2026. Voici comment retirer l’accès de Sowilo à Facebook et supprimer les données de Sowilo Réseaux.

1. Retirer l’autorisation Facebook

Dans les paramètres de votre compte Facebook, recherchez les applications connectées dans « Applications et sites web » ou « Intégrations professionnelles », selon votre configuration. Sélectionnez l’application Sowilo et retirez son accès. Vous pouvez aussi utiliser les outils Meta pour révoquer le jeton concerné. Les intitulés peuvent évoluer selon l’interface Facebook.

Dans Sowilo Réseaux, Configuration → « Oublier le jeton » efface le jeton saisi de la session. Fermez ensuite l’application. Cela ne révoque pas le jeton auprès de Meta. Si un jeton est fourni par une variable d’environnement, retirez aussi cette variable de votre configuration de lancement.

2. Supprimer les données sur votre ordinateur

Fermez Sowilo Réseaux et tout module qui l’utilise avant de supprimer les fichiers. Dans le gestionnaire de fichiers, activez l’affichage des fichiers cachés, puis supprimez les dossiers propres à l’application :

  • ~/.local/share/sowilo-reseaux/ : base des brouillons, textes, liens et historique des publications ;
  • ~/.config/sowilo-reseaux/ : identifiant et nom attendus de la Page et version de l’API.

Si des racines XDG personnalisées sont configurées, ces dossiers se trouvent sous $XDG_DATA_HOME/sowilo-reseaux/ et $XDG_CONFIG_HOME/sowilo-reseaux/. Supprimez uniquement les dossiers « sowilo-reseaux », pas ceux des autres applications.

Cette suppression efface tous les brouillons et tout l’historique local, pas seulement les données d’une Page. Videz également la corbeille et supprimez les éventuelles sauvegardes et exports que vous avez créés. Les images d’origine restent dans leur dossier : supprimez-les séparément si nécessaire. Cette opération ne constitue pas une garantie d’effacement physique des supports.

3. Supprimer les contenus publiés sur Facebook

Les publications déjà envoyées restent sur Facebook après la suppression des fichiers locaux ou le retrait de l’application. Pour les retirer, ouvrez votre Page dans Facebook ou Meta Business Suite et supprimez les publications concernées. Meta conserve ou supprime les données de ses services selon ses propres règles ; Sowilo ne peut pas effacer les données de compte détenues exclusivement par Meta.

4. Demander l’effacement au projet Sowilo

Pour les données détenues par le projet, par exemple un échange email ou un contenu publié sur la Page Sowilo, écrivez à sowiloprojectcontact@gmail.com avec l’objet « Suppression des données Sowilo ». Précisez les données concernées et, si utile, le lien de publication ou l’identifiant de Page. N’envoyez jamais de mot de passe, de clé d’application ou de jeton d’accès.

Nous répondons dans un délai d’un mois. Si la demande nécessite une prolongation prévue par la loi, nous vous en expliquons la raison dans ce délai. Une vérification proportionnée de votre identité peut être nécessaire ; toute conservation légalement nécessaire vous sera expliquée. Les installations locales sont sous le contrôle de leur utilisateur : Rémy n’accède pas à distance à leurs fichiers.

Pour comprendre les données traitées et vos autres droits, consultez la politique de confidentialité. En cas de difficulté, vous pouvez contacter la CNIL.
